# MyRun — Health Connect + Supabase + AI 러닝 코칭 통합 프로젝트

`MyRun`은 두 개의 독립적인 앱이 하나의 GitHub 저장소(`https://github.com/mage9353/myrun`)와 하나의 Supabase DB(`public.running_logs`, 프로젝트 `running-tracker` / `mwjurzrnkpnqsfqrhaex`)를 공유하는 모노레포입니다.

## 폴더 구조

```text
MyRun/
├── .github/workflows/
│   ├── deploy-pages.yml                  # MyRunCoach/ 폴더만 GitHub Pages로 자동 배포
│   └── release-android.yml               # MyRunSync/ 서명된 Release APK 빌드 및 GitHub Release 배포
├── supabase/
│   └── migrations/
│       └── 001_running_logs_schema.sql   # 단일 진실 원천(DB 스키마, 인덱스, 권한, RLS)
├── MyRunSync/                            # Android Kotlin 앱 (삼성 헬스 → 헬스 커넥트 → Supabase 업로드)
├── MyRunCoach/                           # 정적 웹 대시보드 & Gemini AI 러닝 코치
├── AGENTS.md                             # 에이전트 작업 규칙 (DB 중복 생성 방지)
└── README.md
```

## 각 앱의 역할
* **MyRunSync** (`MyRunSync/`): Android 기기에서 Health Connect의 러닝 세션(야외/트레드밀), 거리, 심박수, 케이던스를 읽어 요약 지표 및 1분 단위 다운샘플링 JSON(`timeseries_1min`)을 계산하고 Supabase `public.running_logs`에 `hc_session_id` 기준으로 `upsert`합니다.
  * Release APK에는 Supabase 키를 내장하지 않으며, 앱 화면의 **Supabase Settings**(`SharedPreferences`)에 `Supabase URL`과 `Anon Key`를 저장해 사용합니다(저장 후에는 입력창이 숨겨지고 `Edit` 버튼으로 수정 가능).
  * **Auto Sync** 섹션에서 **앱 실행 시 자동 싱크** 및 **백그라운드 주기 자동 싱크**(WorkManager, 15분~24시간 주기 선택, `READ_HEALTH_DATA_IN_BACKGROUND` 권한 사용)를 켜고 끌 수 있습니다.
* **MyRunCoach** (`MyRunCoach/`): Supabase `public.running_logs`를 조회해 주간 요약, 추세 차트, 1분 단위 상세 차트 모달, Gemini AI 맞춤 러닝 코칭을 제공하는 단일 파일(`index.html`) 웹 대시보드입니다. GitHub Actions를 통해 `https://mage9353.github.io/myrun/`으로 배포됩니다.

## 공통 DB 계약 (`public.running_logs`)
* **Primary Key**: `id` (`bigint generated by default as identity`)
* **Unique Key (`upsert` 기준)**: `hc_session_id` (`text not null unique`)
* **핵심 컬럼**:
  * 날짜·구분: `run_date` (`timestamptz not null`, 세션 시작 시각), `ended_at` (`timestamptz`), `workout_type` (`text not null`, `'야외'` / `'트레드밀'`), `source_package`, `title`
  * 요약 지표: `distance_km`, `distance_meters`, `duration_sec`, `avg_pace_sec`, `avg_hr`, `max_hr`, `min_hr`, `zone2_min_bpm`, `zone2_max_bpm`, `zone2_ratio` (`0.0~1.0`), `zone2_pct` (`0~100`), `avg_cadence`
  * 1분 시계열 JSONB (`timeseries_1min`):
    ```json
    [
      {
        "minute": 1,
        "offset_sec": 0,
        "timestamp": "2026-11-24T06:00:00Z",
        "hr": 135,
        "max_hr": 140,
        "min_hr": 130,
        "zone2_ratio": 1.0,
        "pace_sec": 300,
        "cadence": 172,
        "distance_m": 200.0
      }
    ]
    ```

## 빌드 & 실행
1. **MyRunSync (Android 로컬 빌드)**:
   * `MyRunSync/local.properties`에 Debug 빌드용 `SUPABASE_URL`, `SUPABASE_ANON_KEY`를 설정할 수 있습니다(Git 제외, Release 빌드에는 포함되지 않음).
   * 빌드 및 단위 테스트:
     ```powershell
     cd MyRunSync
     .\gradlew.bat testDebugUnitTest assembleDebug assembleRelease
     ```
2. **MyRunSync GitHub Releases & Obtainium 설치**:
   * `.github/workflows/release-android.yml`은 `v*` 태그(예: `v1.0.0`) 푸시 또는 GitHub Actions `workflow_dispatch` 실행 시 서명된 `MyRunSync-vX.Y.Z.apk`를 GitHub Releases에 업로드합니다.
   * 필요한 GitHub Repository Secrets 4개:
     * `ANDROID_KEYSTORE_BASE64` (`.jks` 키스토어의 Base64 문자열)
     * `ANDROID_KEYSTORE_PASSWORD`
     * `ANDROID_KEY_ALIAS`
     * `ANDROID_KEY_PASSWORD`
   * Android 기기의 **Obtainium**에서 저장소 URL `https://github.com/mage9353/myrun`을 추가하면 최신 Release APK 설치 및 자동 업데이트를 받을 수 있습니다.
3. **MyRunCoach (Web)**:
   * `MyRunCoach/index.html` 또는 GitHub Pages(`https://mage9353.github.io/myrun/`)를 열고 **[⚙️ API 설정]**에 Supabase URL/Anon Key, Gemini API Key를 입력합니다.
